# English edition — production status

This tree is the English track of the handbook. It grows **batch by batch,
following the v2 rewrite of the Chinese source track**:

- The Chinese tree ([zh/](../zh/README.md)) is the source of truth. Each
  translated batch mirrors a zh batch that already passed review; translation
  goes through the same release gate.
- The complete v1.0 edition exists only in Chinese (frozen as tag `v1.0.0`)
  and is not being back-translated.

Planned structure (mirrors `zh/`):

overview → cordis → agent-runtime → llm-layer → platform → execution →
augmentation → deep/ (29 source-level deep dives) → background/ (concepts a
first-time reader may lack)
